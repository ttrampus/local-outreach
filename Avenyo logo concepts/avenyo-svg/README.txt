Avenyo — logo files

mark/     the symbol alone (100x100 grid)
lockup/   symbol + wordmark
icon/     app icon and favicon tiles

Colours
  Ink      #1E2227
  Signal   #2C6BE4   (light-on-dark: #6098FF)
  Paper    #FAFAFA

Type
  Wordmark is Archivo Bold (700), letter-spacing ~0.005em.
  The lockup SVGs use live <text>, so Archivo must be installed to render
  correctly. For production, open in a vector editor and convert text to
  outlines, or ask and I'll supply outlined versions.

Rules
  Clearspace: half the mark height on all sides.
  Minimum mark size: 18px. Below 28px use the icon tile, not the lockup.
  Don't recolour the lanes; only the centre marker carries the accent.
